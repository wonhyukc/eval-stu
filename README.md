학생들의 과제 이메일을 수집(Gmail)하고, 채점 결과를 구글 시트(Google Sheets)에 연동하여 관리하는 Python 자동화 저장소입니다.

> **강의안·교재 개발**은 형제 저장소 `../stu2603`에서 수행합니다.
> 과목별 교재·과제 자료는 `../py2608-stu`(파이썬), `../web2608-stu`(웹)에 있습니다.

> ⚠️ **출결(출석·결석·지각·조퇴) 관련 내용은 이 저장소의 관할이 아닙니다.**
> 출결 데이터 조회·수정은 **`stu` 저장소(`../stu2603`)** 에서 확인하세요.

## 🎯 주요 기능

- **이메일 초고속 수집 및 채점**: 수신된 이메일의 제목 키워드(`과제`, `assignment`)를 파싱하여 학번을 식별하고, 기한 및 규격 준수 여부에 따라 5단계 티어(1.0/0.9/0.7/0.5/0.2/0.0) 자동 채점
- **미답장 건 핀포인트 자동 답장**: 이미 답장된 메일은 건너뛰고, 미답장 건에 한하여 트랙별 언어 정책(웹 1·2반 영문, 파이썬 4반 한글)에 맞춘 피드백 답장(Reply) 자동 발송
- **채점 및 답장 종합 통계**: 반별 점수 분포 요약 표와 함께 답장 3대 지표(총 답장 건수, 이미 답장 완료, 이번에 답장 완료) 실시간 출력
- **구글 시트 연동**: 채점 결과를 학생별/과목별 구글 스프레드시트에 멱등(Upsert) 동기화
- **채점 규칙 SSOT**: 감점 기준·시트 포맷·언어 정책 등 채점 규칙을 문서화
- **안전한 격리 브라우저 세션**: 메인 크롬 무간섭 원칙에 따라 독립 전용 디렉터리(`~/.config/eval-stu-grader`)에서 안전하게 실행

## 🔐 인증 및 자격 증명 (Credentials)

프로젝트 내 Google API 통합을 위해 환경에 따라 다음과 같은 인증 파일이 요구될 수 있습니다. (주로 `secret.json` 사용)

| 파일명 | 용도 및 설명 |
|---|---|
| **`secret.json`** | **(메인)** 사용자의 개입 없는 백그라운드 환경용 서비스 계정 개인키입니다. 타겟 스프레드시트에 편집자 권한으로 계정 이메일을 공유해야 쓰기가 가능합니다. |
| **`credentials.json`** | 관리자(교강사) 계정으로 인증 절차를 밟기 위한 OAuth 2.0 클라이언트 ID 파일입니다. |
| **`token.json`** | `credentials.json` 최초 인증 후 발급받아 재사용하는 권한 갱신용 접속 토큰 파일입니다. |

> ⚠️ **보안 주의**: 모든 인증 JSON 파일은 절대 Git 저장소에 포함되지 않도록 `.gitignore`에 등록하여 관리해야 하며, AI 에이전트의 접근도 엄격히 제한됩니다.

bin/harness-check.sh

## 🚀 이메일 과제(0.x) 통합 고속 채점 가이드 (`grade.sh`)

Playwright를 활용해 Gmail 목록을 초고속(수 초 내)으로 스캔하고 채점, 구글 시트 동기화, 그리고 **미답장 건에 한하여 핀포인트 자동 답장 발송**까지 단일 쉘 스크립트로 제어합니다.

### 1. 주요 동작 모드

```bash
# [기본] 초고속 채점 + CSV 저장 (미리보기, 시트/답장 X)
./bin/grade.sh 0.5

# [시트 반영] 채점 결과 구글 시트 동기화 (Upsert)
./bin/grade.sh 0.5 sync

# [답장 발송] 미답장 메일에 대해서만 트랙별 언어(영/한)로 핀포인트 답장 발송
./bin/grade.sh 0.5 reply

# [원클릭 전체] 채점 + 구글 시트 반영 + 자동 답장 발송을 한 번에 완료
./bin/grade.sh 0.5 all
```

### 2. 고속 부분 타겟팅 필터 (트랙, 특정 학생)

불필요한 스레드 진입 없이 원하는 대상만 콕 집어서 초고속으로 처리할 수 있습니다:

```bash
# 특정 트랙만 채점 (web1, web2, py)
./bin/grade.sh 0.5 web1

# 4반(파이썬) 미답장자에게만 답장 발송
./bin/grade.sh 0.5 reply py

# 특정 학생 1명만 확인 (끝 3자리 또는 전체 학번)
./bin/grade.sh 0.5 --id 742

# 특정 학생 1명에게만 확인 후 답장 발송
./bin/grade.sh 0.5 reply --id 742
```

### 3. 채점 결과 및 답장 현황 요약 (터미널 출력 예시)

어떤 동작 모드나 필터를 적용하든, 채점 완료 시 반별 5단계 점수 분포와 답장 3대 지표가 명확하게 출력됩니다:

```text
=================================================================
📊 [채점 결과 요약]
-----------------------------------------------------------------
반 | 채점대상 | 1점  | 0.9점 | 0.7점 | 0.5점 | 0.2점 | 0점
-----------------------------------------------------------------
4  |    13    |  5   |   1   |   0   |   0   |   0   |  0
1  |    31    |  11  |   3   |   0   |   0   |   0   |  0
2  |    32    |  11  |  12   |   0   |   0   |   0   |  7
-----------------------------------------------------------------
✉️ [답장 현황]
• 총 답장 건수   : 43건 (전체 제출 50건 중 86.0%)
• 이미 답장 완료 : 35건
• 이번에 답장 완료: 8건 (미답장 잔여: 0건)
=================================================================
```

- **전용 크롬 프로세스 종료**: `./bin/stop_grader_chrome.sh`
