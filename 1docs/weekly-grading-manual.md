# 📚 주간 통합 채점 시스템 운영 매뉴얼

이 문서는 파이썬, 웹1, 웹2 트랙의 평가(상호평가, 이메일, 수업 참여 등)를 관리하고 채점하는 전체 과정을 처음 담당하는 사람도 쉽게 이해하고 따라 할 수 있도록 작성된 가이드입니다. 매주 채점을 진행하실 때 이 문서를 보며 순서대로 따라오시면 기억을 쉽게 더듬을 수 있습니다.

---

## 1. 시스템이 돌아가는 원리 (Architecture Overview)

우리의 채점 시스템은 교수의 개입을 최소화하면서도 유연하게 대응하기 위해 다음과 같이 연결되어 있습니다.

1. **단일 구글 폼 & 구글 시트**
   - 학생들은 과목(트랙)에 상관없이 **하나의 구글 폼**으로 과제나 평가를 제출합니다.
   - 모든 응답은 하나의 구글 시트에 차곡차곡 쌓입니다.
2. **마감일 자동 판별**
   - 폼을 하나만 쓰기 때문에 과목별(파이썬, 웹1, 웹2)로 마감 시간이 달라도 폼을 임의로 닫을 수 없습니다.
   - 마감 시간을 기준으로 스크립트가 타임스탬프(제출시간)를 읽어 기한을 넘긴 지각자를 자동으로 '0점' 혹은 '감점' 처리합니다.
3. **파이썬 채점 자동화 스크립트 (`check_evaluations.py`)**
   - 매주 이 스크립트를 실행하면:
     - 시트에서 아직 채점되지 않은 **'대기' 상태의 새로운 제출 건**만 가져옵니다.
     - 다수결 원칙 등을 적용해 점수를 계산합니다.
4. **결과 파일 자동 분배 및 업로드 (Split & Auto-Append)**
   - 스크립트는 계산된 최종 점수를 각 과목별(파이썬, 웹1, 웹2)로 분리하여 **기존에 존재하는 3개의 개별 파일(또는 시트) 최하단에 각각 자동으로 이어붙이기(Append)** 합니다. 
   - 이를 통해 기존에 구축된 다른 파이썬 코드들을 수정할 필요 없이 호환성을 완벽하게 유지합니다.

## 2. 매주 채점하기: Step-by-Step 가이드

### 📍 1단계: 채점 스크립트 실행
작업 공간에서 터미널(명령 프롬프트)을 열고 채점 스크립트를 실행합니다. 과목(`--course`)과 주차(`--week`)를 옵션으로 입력합니다.

- **파이썬 트랙 10주차 채점 실행 예시:**
  ```bash
  .venv/bin/python bin/check_evaluations.py --course py --week 10
  ```
- **웹 트랙 10주차 채점 실행 예시:**
  ```bash
  .venv/bin/python bin/check_evaluations.py --course wb --week 10
  ```

### 📍 2단계: 실행 결과 확인 (터미널 로그)
명령어를 치고 엔터를 누르면, 스크립트가 알아서 구글 시트와 통신하며 채점을 진행합니다. 터미널 화면에서 다음 메시지들이 나오는지 확인합니다.
- *"데이터를 가져왔습니다."*
- *"지각자 식별 완료: 0점 처리됨."*
- *"✅ 채점 완료. 각 과목별 파일에 결과를 자동 분배 및 업로드했습니다."*

### 📍 3단계: 구글 시트에서 최종 점검 및 조정
이제 구글 시트를 열어 스크립트가 잘 일했는지 확인합니다.

1. **응답 시트 (제출 내역)**: 방금 채점이 끝난 학생들의 우측 '채점 상태' 컬럼이 `[x] 완료`로 마킹되어 있는지 확인합니다.
2. **최종 결과 파일/시트**: 각 과목별 결과 파일(`py`, `wb1`, `wb2`) 맨 밑바닥을 보면 방금 돌린 스크립트의 결과가 새로운 행으로 추가(Append)되어 있습니다.

> 💡 **재채점이 필요한 경우 대처법**
> 특정 학생의 점수에 누락이나 문제가 있어 스크립트를 다시 돌리거나 부분 재채점을 하는 경우가 생길 수 있습니다. 
> 이 시스템은 기존 결과를 강제로 지우거나 덮어쓰지 않습니다. 무조건 **최하단에 새로운 결과 줄을 추가**하기만 합니다. 
> 따라서, 결과 파일에 중복된 결과(과거 잘못된 점수와 방금 새로 뽑은 점수)가 보인다면, **교수님께서 직접 눈으로 비교해 보시고 잘못된 과거 행을 삭제**해 주시면 됩니다. (가장 안전하고 단순한 방식입니다.)

## 3. 이메일 기반 과제(0.x) 채점 가이드 (`grade.sh`)

> 📖 **단일 규칙 원천(SSOT)**: 마이크로 과제(0.x)의 세부 채점 기준, 배점 티어, 사전 검수 주의사항 등 모든 상세 규칙은 **[`1docs/score-email.md`](file:///home/hyuk/prj/stu/eval-stu/1docs/score-email.md)**를 단일 원천으로 참조합니다.

파이썬 및 웹 과정 학생들의 **메일 과제(0.x)** 채점은 데이터 무결성을 위해 `grade.sh` 스크립트를 사용하여 4단계(크롤링 → CSV 검수 → 시트 동기화 → 시트 정렬)로 진행합니다.

### 📍 표준 실행 순서 (예: 4주차 0.4 과제)

1. **Gmail 크롤링 및 로컬 CSV 저장**:
   ```bash
   ./bin/grade.sh 0.4
   ```
   - Gmail에서 해당 주차 과제 메일을 수집하고 자동 채점하여 `output/mail04.csv` 파일로 저장합니다. (시트 업로드 없음)

2. **[필수] CSV 사전 검수 및 노이즈 정제**:
   - `output/mail04.csv` 파일을 열어 최하단 행의 비과제 메일(Google 보안 알림, 교수 공지 메일)을 삭제합니다.
   - 학번이 누락된 학생(예: `Sumit Sarraf`)은 학번과 트랙을 수기 입력합니다.
   - ⚠️ **주의**: 미식별 행을 그대로 두고 sync를 실행하면 **웹 2반(web2) 시트에 0점으로 자동 등록**되므로 반드시 정제 후 진행합니다.

3. **구글 시트 동기화 (Sync)**:
   ```bash
   ./bin/grade.sh 0.4 sync
   ```
   - 검수가 완료된 CSV 데이터를 파이썬(4반) 및 웹(1반/2반) 구글 시트에 자동 분기 업로드합니다.

4. **구글 시트 정렬 (Sort)**:
   ```bash
   ./bin/grade.sh 0.4 sort
   ```
   - 시트 데이터를 4단계 표준 정렬(주차 역순 → 대분류 → 세부유형 → 학번 오름차순)로 정렬하고 일련번호(No)를 재부여합니다.
