# [3test] 마감일 및 채점 트래킹 테스트 시나리오

## 시나리오 1: 마감일 자동 판별 및 0점 처리 테스트
- **Given**: `deadlines.json`에 특정 과목(예: `py`) 10주차 마감일이 "2026-05-10 23:59:00"으로 설정됨.
- **When**: 
  - A학생: "2026-05-10 23:58:00" 제출
  - B학생: "2026-05-11 00:01:00" 제출 (지각)
- **Then**: 
  - 스크립트 실행 후 A학생은 정상 점수가 부여되어야 함.
  - B학생은 터미널 로그에 '지각'으로 명시되고, 최종 CSV 결과에서 산출 점수가 0점(또는 심한 감점 기준치)으로 강제 적용되어야 함.

## 시나리오 2: 다중 과목 마감일 독립 적용 테스트
- **Given**: 단일 시트에 `py`와 `wb` 과목의 제출건이 섞여 있음. `py` 마감일은 금요일, `wb` 마감일은 일요일로 설정됨.
- **When**: 토요일에 제출한 A(`py` 트랙)와 B(`wb` 트랙)의 타임스탬프를 처리함.
- **Then**: A는 금요일 마감을 넘겼으므로 0점 처리되고, B는 일요일 마감 전이므로 정상 점수로 처리되어야 함.

## 시나리오 3: 채점 완료 상태 트래킹 테스트 (중복 채점 방지)
- **Given**: 지난 번에 실행되어 시트 상에 '완료' 상태로 마킹된 데이터가 존재함.
- **When**: 스크립트를 재실행함.
- **Then**: '대기' 상태인 신규 제출 건에 대해서만 채점 로직이 돌아가며, 이미 '완료'된 항목은 점수 산출 및 API 통신에서 건너뛰어야(Skip) 함.
