# [1prd] 단일 폼 기반 통합 채점 관리 아키텍처

## 1. 개요 (Background)
* 파이썬, 웹1, 웹2 트랙의 이메일, 상호평가, 수업 참여 평가가 모두 **하나의 구글 폼**을 통해 수집되고 있음.
* 과목(트랙)별로 **제출 마감 시간이 다름**.
* 폼 하나를 공용으로 사용하므로 특정 과목 마감일이 지났다고 해서 폼 제출을 닫을 수 없음.
* 조교 없이 1인 체제로 운영되므로, 직관적인 진척도 관리와 자동화된 지각 분류가 필수적임.

## 2. 해결 과제 (Problem Statement)
* **단일 폼의 한계**: 과목별 마감 시간이 달라 폼의 기본 기능(제출 마감)을 사용할 수 없음.
* **진척도 파악의 부재**: 단일 시트에 계속 데이터가 쌓이면서 어디까지 채점했는지, 새로 들어온 건이 무엇인지 직관적으로 구분하기 어려움.
* **수동 결과 취합의 번거로움**: 로컬에서 생성된 채점 결과(CSV)를 매번 구글 시트에 수동으로 복사하여 붙여넣고 있어 시간 낭비가 큼.

## 3. 핵심 요구사항 (Core Requirements)
1. **과목별 독립 마감일 자동 판별 기능**
   * 과목명(파이썬, 웹1, 웹2)에 따라 서로 다른 기준 마감일(Deadline)을 적용.
   * 제출된 타임스탬프와 해당 과목의 마감일을 비교하여 '기한 내(On-time)'와 '지각(Late)'을 자동 판별 및 감점 처리.
2. **채점 결과 시트 자동 업로드 (Auto-Append)**
   * 파이썬 스크립트 실행 후 생성된 결과(CSV)를 **과목별 개별 파일(시트)의 결과 탭 최하단에 자동으로 이어붙이기(Append)**.
   * **재채점 로직 (단순화)**: 재채점으로 인한 중복 데이터가 발생해도 무조건 최하단에 추가하며, 최종적인 중복 확인 및 조정은 교수가 직접 시트에서 눈으로 보고 수행함.
3. **단순화된 채점 상태 트래킹 (Status Tracking)**
   * 시트 내에 직관적인 `대기`, `완료` 상태값을 표시.
   * 스크립트에서 이를 읽어 '대기' 상태인 항목만 필터링하여 채점.
4. **SSOT 기반 마감일 관리**
   * 매주 변동되는 마감 시간을 관리하는 설정 파일(deadlines.json)을 도입.

## 4. 해결 방향 (Solution Design)
* **스프레드시트 뷰 개선**: 응답 시트 맨 우측에 `채점 상태`, `마감일 기준 지각 여부` 컬럼 확보.
* **Python 채점 엔진 고도화**: `check_evaluations.py` 스크립트에서 Timestamp 파싱 및 마감일 대조 로직 추가.
* **Google Sheets API 쓰기 권한 추가**: 스코프(`SCOPES`)를 `spreadsheets` 쓰기 권한으로 넓히고, `spreadsheets().values().append()` 메서드를 사용해 결과 자동 기록 구현.
