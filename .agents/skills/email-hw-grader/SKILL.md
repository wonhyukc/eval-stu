# Email HW Grader Skill (이메일 과제 채점, 시트 연동 및 자동 답장 스킬)

Gmail 수신함에서 학생들의 과제 제출 이메일을 크롤링·파싱하고, 기한 및 제목 양식 준수 여부를 채점하여 각 과목의 구글 스프레드시트 `score` 탭에 **멱등(Idempotent)하게 동기화**하며, **아직 답장을 보내지 않은 메일(미답장 건)에 한하여 트랙별 언어 정책에 맞춘 확인/피드백 답장(Reply)을 발송**하는 전문가 스킬입니다.

## 🌐 1. 배포·공유 자료 트랙 언어 100% 일치 원칙

학생들에게 배포 및 공유되는 모든 자료(스프레드시트, 과제 피드백, 안내문 등)는 **해당 트랙의 강의 언어와 100% 일치**해야 합니다:

### ① E트랙 (영어 트랙: 1반 / 2반 웹프로그래밍)
- 외국인 유학생 대상 수업이므로 스프레드시트의 **헤더뿐만 아니라 모든 셀의 내용(Reason 사유, 유형 등 텍스트 일체)이 예외 없이 100% 영어**로 작성되어야 합니다. (한글 단어 절대 배제)
- **표준 영문 헤더**: `No`, `wk`, `ID`, `Track`, `Score`, `Type1`, `Type2`, `Reason`, `Date`, `Name`, `Subject`
- **표준 영문 사유(Reason) 매핑**:
  - 정확한 준수 (1.0점): `On-time & Exact Format`
  - 관용 인정 / 경미 오차 (0.9점): `Minor format issue (Brackets/Extra text)`
  - 형식 미흡 / 학번 누락 (0.7점): `Missing Student ID or 0.x in Subject`
  - 지각 제출 (0.5점): `Late submission (Before next class)`
  - 지각 + 형식 미흡 (0.2점): `Late & Format Issue (Missing ID)`
  - 미제출 (0.0점): `No submission`
  - 본문 미작성 / 불인정 (0.0점): `Empty Body / Quoted Text Only`

### ② K트랙 (한국어 트랙: 4반 컴퓨팅적사고와코딩)
- 한국어 대상 수업이므로 스프레드시트의 **헤더뿐만 아니라 모든 셀의 내용(이유 사유, 유형 등 텍스트 일체)이 예외 없이 100% 한국어**로 작성되어야 합니다.
- **표준 한글 헤더**: `no`, `주차`, `학번`, `트랙`, `점수`, `유형1`, `유형2`, `이유`, `날짜`, `이름`, `메일제목`
- **표준 한글 사유(이유) 매핑**:
  - 정확한 준수 (1.0점): `정상 제출 (기한내/정확한 양식)`
  - 관용 인정 / 경미 오차 (0.9점): `경미한 양식 오차 (괄호/불필요 기호)`
  - 형식 미흡 / 학번 누락 (0.7점): `제목 학번 또는 과제명 누락`
  - 지각 제출 (0.5점): `지각 제출 (다음 수업 시작 전)`
  - 지각 + 형식 미흡 (0.2점): `지각 + 제목 학번 누락`
  - 미제출 (0.0점): `미제출`
  - 본문 미작성 / 불인정 (0.0점): `본문 미작성(단순 회신)`

### 📋 5단계 티어 배점 퀵 레퍼런스 (1.0점 만점)

| 최종 점수 | 판정 유형 | 핵심 판정 요건 |
|:---:|:---:|---|
| **1.0점** | **정상 만점 (Exact Format)** | 기한 내(목 23:59 + 15분 유예) + 제목 `0.x` & 10자리 학번 정확 준수 + 순수 본문 존재 |
| **0.9점** | **관용 인정 (Minor Format)** | 기한 내 + 본문 충실하나 **대괄호 `[]`, 소괄호 `()`, 마침표 오타, 라벨 문구 등 경미 오차** (-0.1점) |
| **0.7점** | **형식 미흡 (Format Issue)** | 기한 내 + 본문 충실하나 **제목에 학번 누락 또는 과제명 누락/오기** (-0.3점) |
| **0.5점** | **지각 제출 (Late Submission)** | **마감 시간 초과 후 다음 수업 시작 시각 전까지 제출** (-0.5점) + 학번 정상 준수 |
| **0.2점** | **지각 + 형식 미흡** | 다음 수업 시작 전까지 제출(-0.5점) **+** 제목 학번 누락(-0.3점) *(누적 감점)* |
| **0.0점**<br>*(시트 등록)* | **불인정 / 미제출 (0점 등록)** | 다음 수업 시작 시각 초과, **빈 껍데기 회신(본문 미작성)**, 과제 메일 미발송자 (시트에 0점으로 등록) |

- **마감 및 유예**: 목 23:59 (+15분 유예, 금 00:15까지 1.0점 인정, 다음 수업 시작 시각 전까지 지각 허용)
  - 4반 (py): 월 09:00 전
  - 2반 (web2): 월 13:00 전
  - 1반 (web1): 월 16:00 전
- **다중 발송 멱등성**: 마감 전 정상 제출본(1.0점)이 있다면 마감 후 추가 제출이 있어도 1.0점 유지
- **순수 본문 유효성**: 인용문 제외 30자 이상 또는 유효 URL 필수 (미충족 시 0점 불인정)
- *상세 정책 및 예외 처리 규정은 [`1docs/score-email.md`](file:///home/hyuk/prj/stu/eval-stu/1docs/score-email.md)를 확인하십시오.*

## 🔤 4. 구글 시트 데이터 타입 및 강제 포맷팅 규칙

구글 시트가 텍스트를 숫자나 날짜로 자동 변환하여 데이터가 왜곡되는 것을 방지하기 위해 다음 2중 안전장치를 강제합니다:

1. **Type2 열 (과제 유형)**:
   - 과제 번호(예: `0.1`)가 실수 숫자로 오인되지 않도록 **반드시 접두사 `'`(작은따옴표)를 붙여 항상 문자열(`'0.1`)로 입력**합니다.
2. **K열 (Subject / 메일제목) 및 C열 (ID / 학번)**:
   - 학생이 메일 제목에 학번 등 순수 숫자만 적어 보낸 경우(예: `2026300742`), 구글 시트가 10자리 숫자로 감지하여 지수 표기(`2.03E+09`)로 왜곡하거나 우측 정렬(Right-aligned)하는 것을 방지합니다:
     - **값 입력 시**: 접두사 `'`(작은따옴표)를 붙여 순수 문자열(`'2026300742`)로 전송
     - **셀 서식 강제**: 시트 셀 서식을 **`NumberFormat: TEXT`** 및 **`HorizontalAlignment: LEFT` (좌측 정렬)**로 고정

## ⚡ 5. 채점 및 시트 동기화 멱등성 (Idempotency) 보장 원칙

동일한 채점 스크립트를 **몇 번을 반복 실행하더라도 시트와 결과 파일의 상태는 항상 동일한 단일 상태로 수렴**해야 합니다:

1. **단순 Append 금지**: 실행할 때마다 중복 행이 무한정 늘어나는 방식을 금지합니다.
2. **복합 키 기반 Upsert**:
   - 고유 복합 키: `(StudentID, Type1, Type2)` (예: `2026300742`, `hw`, `0.1`)
   - **기존 데이터 존재 시**: 해당 행의 점수, 사유, 일시를 **새 채점 값으로 덮어쓰기(Update)**.
   - **기존 데이터 미존재 시**: 신규 행으로 **추가(Append)**.
3. **0점 미제출자 등록**:
   - 전체 수강생 명부와 제출자를 대조하여 미제출자는 0.0점으로 시트에 등록합니다.
4. **일련번호(No) 유지 및 자동 증가**:
   - 기존 행 갱신 시 기존 `No`를 유지하고, 신규 행 추가 시 `max_no + 1`부터 순차적으로 부여합니다.

## ✉️ 6. 답장 발송 정책 (미답장 건 한정 및 언어 준수 원칙)

과제 메일 채점 후 학생에게 피드백 또는 수신 확인 메일을 발송할 때의 필수 규칙입니다:

1. **미답장(Unreplied) 메일에 대해서만 발송 (필수)**:
   - 해당 메일 스레드(Thread)에서 **이미 본인(교강사 `wonhyukc@stu.ac.kr`)이 답장한 이력이 있는 스레드는 절대 중복 답장하지 않습니다.**
   - 스레드의 마지막 메시지가 학생 발신인 건(또는 Gmail 검색 시 `-from:wonhyukc@stu.ac.kr` 및 스레드 메시지 발신자 검사)에 대해서만 답장을 수행합니다.
   - 학생 1인이 여러 번 재제출한 경우에도 최신 유효 제출본 1건에 대해서만 답장합니다.
2. **트랙별 언어 정책 100% 준수**:
   - **E트랙 (1반 / 2반 웹프로그래밍)**: **100% 영문**으로 답장 본문 작성.

       ```text

       Your assignment submission has been received and graded successfully.

       Thank you!
       ```
     - **형식 위반/지각 제출 시 예시**:
       ```text
       Hello [Student Name],

       Your assignment submission has been reviewed:
       - Task: [Type]
       - Note: [Reason, e.g., Missing Student ID in Subject / Late submission] (Score: 0.7/1.0)

       Please make sure to follow the format and deadline for future assignments.
       ```
   - **K트랙 (4반 컴퓨팅적사고와코딩)**: **100% 한글**으로 답장 본문 작성.
     - **정상 제출 시 예시**:
       ```text
       안녕하세요 [학생이름] 학생,

       과제 이메일이 정상적으로 접수 및 채점되었습니다.
       - 과제: [유형]
       - 상태: 정상(학번O, 기한내O) (점수: 1.0/1.0)

       ```
     - **형식 위반/지각 제출 시 예시**:
       ```text

       규정에 맞춰 다음 과제 제출 시 유의해 주시기 바랍니다.
       ```

### 4. 발송 메커니즘 및 브라우저 세션 제어 원칙:
   - **메인 크롬 절대 무간섭 (Zero-Interference)**:
     - 사용자가 평소 작업 중인 메인 크롬 창은 절대 닫지 않으며, `pkill chrome` 등의 전체 강제 종료 명령을 사용하지 않습니다.
   - **단일 전용 프로필 백그라운드 구동**:
     - `google-chrome --user-data-dir=$HOME/.config/eval-stu-grader --remote-debugging-port=9222` 형태로 백그라운드 구동하여 CDP(9222)로 연결합니다.
     - 작업 완료 시 오직 해당 전용 프로세스만 안전하게 종료합니다.
