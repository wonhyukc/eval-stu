# TIS Grade Input Automation Skill

이 스킬은 학교 종합정보시스템(TIS)의 성적 입력 페이지(Exria 프레임워크 기반)에 학생들의 성적(중간, 기말, 과제, 출석 등) 및 석차 기준 등급(A+, B+, C+ 등)을 자동으로 입력할 때 사용하는 표준 워크플로우를 정의합니다.

## 언제 사용하나요?
- 사용자가 TIS(tis.stu.ac.kr) 포털에 특정 분반의 성적 데이터를 일괄 기입해 달라고 요청할 때.
- 원본 채점 데이터를 바탕으로 석차를 기준 삼아 등급(A+, B+, C 등)을 일괄 입력해 달라고 요청할 때.

## 에이전트 행동 지침 (0 ~ 5단계 표준 워크플로우)

에이전트는 사용자의 성적 입력 요청이 들어오면 다음 6단계에 맞춰 순차적으로 작업을 안내하고 스크립트를 작성하여 가동합니다.

---

### 0단계: 사전 준비 및 브라우저 실행 안내 (0. 샌드박스 브라우저 띄고 로그인)
원격 제어를 위해 사용자의 화면에 크롬 디버깅 포트(9222)를 연 크롬 브라우저를 띄워야 합니다.
1. 사용자에게 열려 있는 모든 크롬 브라우저를 완전히 종료하도록 안내합니다.
2. 터미널 혹은 에이전트 백그라운드 명령으로 디스플레이 환경변수를 명시해 크롬을 켭니다.
   ```bash
   google-chrome --remote-debugging-port=9222
   ```
3. 사용자가 띄워진 브라우저 화면에서 **TIS 포털에 로그인**하도록 안내합니다.

### 1단계: 대상 분반 조회 (1. 해당 트랙을 화면에 띄운다)
1. 사용자가 TIS 시스템 내에서 성적을 입력할 **해당 교과목 분반(트랙)**을 선택하고 **[조회]** 버튼을 클릭하도록 유도합니다.
2. 에이전트는 Playwright CDP 연결 테스트를 통해 화면에 해당 프레임(`cgdCRecInput`)이 정상 로드되었는지 검증합니다.

### 2단계: 성적 산출 기준 변경 (2. 점수 기준 표를 고친다. 저장)
1. 분반마다 중간고사, 기말고사, 과제, 출석 등의 만점 기준이나 반영 비율이 다를 수 있습니다.
2. 사용자가 성적 입력 테이블 상단의 **[산출기준변경]** 단추를 눌러 비율 설정을 화면 기준과 일치하도록 고치고 **[저장]**을 완료했는지 확인 및 안내합니다.

### 3단계: 채점표 데이터 파싱 및 기입 (3. 채점표를 복/붙한다.)
1. 사용자로부터 `학번 중간 기말 과제 출석` 형태의 텍스트 채점 데이터를 입력(복사/붙여넣기)받습니다.
2. 에이전트는 첫 번째 헤더 행을 기준으로 열 순서를 파악해 파이썬 딕셔너리로 동적 매핑합니다. (예: `학번 기말 중간 토론 과제` 처럼 순서나 컬럼명이 변경되어도 알아서 동적 파싱되도록 설계합니다.)
3. `cgdCRecInput` 프레임 내의 Exria Grid API(`rptCgdRecInput`)를 호출하여 각 행의 학번 매칭 확인 후, 아래의 매핑 코드에 맞추어 값을 입력합니다.
   - `EVAL_SCR1` -> 중간고사
   - `EVAL_SCR2` -> 기말고사
   - `EVAL_SCR3` -> 과제/수업참여
   - `EVAL_SCR4` -> 출석 (만약 "출석 비움" 조건이 있다면 공백 `""` 처리)
4. 점수 입력 후 그리드 새로고침(`ctrl.redraw()`)을 실행합니다.

### 4단계: 석차 기준 등급 기입 (4. 석차 기준 등급을 제시한다.)
1. 사용자로부터 석차 분할 기준을 입력받거나, **성적정정기간 마지막(이의신청 대비 버퍼 규칙)**에 따라 자동으로 등수를 계산합니다.
   - **이의신청 대비 버퍼 규칙 (총원 $N$명 기준)**:
     - **A학점 상한**: $\lceil N \times 0.4 \rceil$ 등수에서 **1명 적게** 부여 (최대 $\lceil N \times 0.4 \rceil - 1$ 등까지 A+)
     - **B학점 누적 상한**: $\lceil N \times 0.8 \rceil$ 등수에서 **2명 적게** 부여 (최대 $\lceil N \times 0.8 \rceil - 2$ 등까지 B+)
     - **그 이하 등수**: `C0` (또는 지정 등급)으로 입력
2. 에이전트는 각 행의 `RNK` (석차) 컬럼 값을 읽어와 정수로 파싱합니다.
3. 조건에 맞는 등급 코드(`GRD_RCD`) 값을 설정합니다.
   - `A+` -> `CGD002A+`
   - `B+` -> `CGD002B+`
   - `C+` -> `CGD002C+`
   - `C0` -> `CGD002C0` (표준 C 학점)
   - `D` -> `CGD002D`
   - `F` -> `CGD002F`
4. 등급 입력 후 그리드 새로고침(`ctrl.redraw()`)을 실행합니다.

### 5단계: 최종 저장 안내 (5. 저장 버튼을 누르라고 안내한다.)
1. 모든 기입이 완료되면 최종 화면의 스크린샷(`tmp/final_grades_screenshot.png`)을 캡처하여 검증 리포트(`walkthrough.md`)에 첨부해 보여줍니다.
2. 입력 상태에 이상이 없다면, 사용자에게 브라우저 화면 우측 상단의 **[저장]** 버튼을 직접 클릭하여 서버에 최종 제출할 것을 안내합니다.
